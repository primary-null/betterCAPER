# Security Policy

## Supported Versions

Security fixes target the latest release and the `main` branch. Install APKs only from the [Releases page](https://github.com/primary-null/betterCAPER/releases) and check the signing certificate as described in the README; CI debug builds are not releases.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for security problems.

Include the affected version, steps to reproduce using a test network, and the impact. Never include credentials, private keys, or captures of third-party traffic.
